# LPES – Computational Approaches (HS26)

每个 Exercise 采用相同的结构：

| 文件夹 | 内容 |
|---|---|
| I_brief | 作业说明 (script) + 对应讲座 PDF |
| II_literature | 指定文献 |
| III_data_raw | 原始数据，**只读，不要改** |
| IV_data_processed | 裁剪、栅格化、重分类后的中间数据 (.tif / .gpkg) |
| V_scripts | Python/R 脚本、notebook 或 QGIS .model3 / ArcGIS .tbx（提交物） |
| VI_outputs | maps / figures / tables 最终结果 |
| VII_portfolio | 作品集排版文件 |

- Exercise_I_Forest_Fragmentation — 伯尔尼州森林破碎化与森林损失驱动因子
- Exercise_II_Urban_Heat_BGI — 城市热岛与蓝绿基础设施（巴塞尔）

文件命名建议：`T{任务号}_{内容}_{时间}_{尺度}.ext`，例如 `T2_forest_AS97_BE.tif`。
